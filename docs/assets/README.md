# Assets

`profilemux-tui.svg` is a capture of the real ProfileMux TUI: the terminal
output of `pmux` running against this machine's actual browser installations,
replayed into a static SVG.

Profile display names and the home directory in the capture are replaced with
neutral placeholders (`Master`, `Work`, `Client A`, `/Users/owner`). Everything
else — the layout, panes, glyphs, sizes and action bar — is the application's
own output, unmodified.
